# Online Library Management System

This project contains the complete database design, documentation, and backend implementation for my Advanced Higher Computing Science capstone project.

Instead of recording all information on paper, I developed a time-efficient system to manage and improve accessibility by tracking borrowed and returned books.

* **Database Management:** Built a detailed 4-relational database structure to store in MariaDB (Book, Customer, Staff, and Borrow tables).
* **Data Integrity:** Integrated a password hash function to prevent unauthorised access and ensure passwords are stored securely in the database. Session variables were used to store all the details, and a unique constraint key was used to prevent duplication.
* **System Modelling:** Developed structural data dictionaries, custom SQL queries, Entity-Relationship Diagrams (ERD), front-end wireframes, and a UML use-case diagram.
